# nelmkt.com · Press Start

A pink, retro video-game portfolio for **Nelly Almaktoum**: researcher & innovator in AI/ML and green tech.

- **Stage 1-1 Player Select** – profile and stats
- **Stage 1-2 Bonus Stage** – *Language Rush*, a mini-game to collect my programming languages
- **Stage 1-3 Quest Log** – Wahaj and Aykah
- **Stage 1-4 Trophy Room** – awards
- **Stage 1-5 Skill Tree** – languages and tools
- **Stage 1-6 Party & Guilds** – community roles
- **Stage 1-7 Save Point** – contact

Built with Next.js, TypeScript, HTML and CSS, exported as a static site and hosted on Cloudflare Pages.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx wrangler pages deploy out --project-name nelmkt
```
